# Showcase cover

`showcase-cover.png` is a screenshot of Scale of the Solar System, showing Jupiter at a zoom level that fits the whole planet on screen.

Jupiter texture: **Solar System Scope**, [source](https://www.solarsystemscope.com/textures/), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). The app projects the texture onto a sphere and adds lighting. The screenshot includes this rendered adaptation; its third-party imagery is not relicensed under MIT.
